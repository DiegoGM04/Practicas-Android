# Cambio de ícono de aplicación

Ejemplo de capas vectoriales para un ícono adaptable, desarrollado sobre el proyecto Practica22.

Para regenerar los íconos: en Android Studio, `app > src > main > res > New > Image Asset`, seleccionar `Launcher Icons (Adaptive and Legacy)` y usar los archivos `ic_launcher_foreground.xml` e `ic_launcher_background.xml` de `res/drawable`.

Este ejercicio es una implementación de práctica; no se ha verificado compilación o ejecución en un emulador.
