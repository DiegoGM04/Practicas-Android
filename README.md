# Prácticas Android

Proyectos de Desarrollo de Aplicaciones para Dispositivos Móviles.

- `practica1`: tarjeta de cumpleaños en Jetpack Compose.
- `ActividadImagenes`: galería de imágenes en Jetpack Compose.
- `Practica22`: pantalla informativa con imagen y texto.
- `cumple`: tarjeta de cumpleaños con diseño XML.
- `CambioIcono`: ejercicio de ícono adaptable.

Los proyectos se organizan en carpetas independientes para Android Studio.
